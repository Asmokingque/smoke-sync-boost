# Design Tokens

Token reference for **BBQ Business Launch**. Use utility classes and CSS variables — never raw values.

## Colors

Apply with any color utility: `bg-<name>`, `text-<name>`, `border-<name>`, `ring-<name>`, `divide-<name>`, etc.

| Name | CSS variable |
|---|---|

| `bbq-charcoal` | `--bbq-charcoal` |
| `bbq-smoke-dark` | `--bbq-smoke-dark` |
| `bbq-smoke` | `--bbq-smoke` |
| `bbq-steel-gray` | `--bbq-steel-gray` |
| `bbq-white` | `--bbq-white` |
| `bbq-bone` | `--bbq-bone` |
